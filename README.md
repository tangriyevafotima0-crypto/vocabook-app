# Vocabook — Test Preparation & Active Recall Engine

An interactive vocabulary acquisition platform and text translation interface tailored for standardized examination preparation (SAT, IELTS) utilizing spaced repetition and context-driven sentence matching.

## System Capabilities
- **Active Recall Engine:** Structured word lists categorized by frequency, difficulty tier, and context clues.
- **Integrated Translator Interface:** Standalone web utility (`translator.html`) allowing rapid bilingual lookup without distracting context switches.
- **Pedagogical Framework:** Comprehensive learning methodology outlined in `LEARNING_METHODOLOGY.docx`.

## Tech Stack
- Frontend / Runtime: Modern Web Technologies (HTML5, CSS3, JavaScript)
- Ingestion Data: Structured vocabulary databases and dictionary mappings
